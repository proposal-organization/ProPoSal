１．事前準備
「proposal-jhs.ai.studio」のURLを直接打ち込んでアクセスしてください。

２．概要と初期設定

デジタル目安箱「ProPoSal」は、生徒の意見をより学校に反映させること、また校則の制定理由を説明し、より納得できる校則制定を目的としたWebアプリケーションです。
投稿は名前を出さずに「匿名」で、賛同は責任を持って行うために実名で行います。

画面左下の「Googleログイン」ボタンを押してください。その後、Googleアカウントでログインしてください。

ログインが完了し、生徒会が正しいアカウントであることを確認して認証すると本格的に使用が可能になります。生徒会認証は順番に行いますので、最大数日程度かかる可能性があります。

「マイページ」からはクラスを設定することができますが、実名で署名するために、アカウント名の変更はできません。

3.使い方

ページ左側にある「意見を投稿」ボタンから、学校生活での疑問や提案内容を記入してください。
内容を記入したら、「AIチェック」のボタンを押してください。公序良俗に反していないかなどをチェックします。不適切な内容の場合は、提出ボタンが現れません。

AIチェックが終了したら、「意見を提出」というボタンを押してください。意見は一度教職員による確認が行われ、適切であると判断されれば意見ボックスに表示されるようになります。

画面左側から意見ボックスのタブを開くと、現在投稿されている意見を確認することができます。この中から自分が賛同したい意見をクリックし、意見の詳細を確認します。そのまま下にスクロールすると「実名で署名（賛同）する」というボタンがあるので、押してください。これで署名ができます。署名すると、自分の名前が表示されます。
署名を解除したい場合は、もう一度署名ボタンを押すと解除できます。

4. ルール
ProPoSalでは、２つのステージで意見を進めていきます。
①７日間で２０人以上の署名を集める「７日間ルール」
→クリアすると１４日間ルールへ
②合計１４日間で３０人以上の署名を集める「１４日間ルール」
→クリアすると生徒会や校則検討委員会で議題に
→検討した結果が生徒会からコメントされる

※意見が多すぎて見づらくなるのを防ぐため、7日間ルール・14日間ルールのいずれかをクリアできなかった意見は削除されます。
