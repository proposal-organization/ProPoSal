# 🕊️ ProPoSal（プロポーザル）

生徒の意見を学校に反映させ、より納得感のある校則制定・学校づくりを目指すための**デジタル目安箱 Webアプリケーション**です。

---

## ✨ 主な特徴

* **匿名で投稿、実名で署名（賛同）**
  * 誰もが気軽に発言できるよう、意見の投稿は**匿名**で行えます。
  * 責任を持って賛同を示すため、署名（賛同）は**実名**で行われます。
* **安心の二重チェック機能**
  * **AIチェック**: 投稿前に公序良俗に反していないかをAIが確認。
  * **教職員チェック**: AIチェック後、教職員が確認を行った上で意見ボックスに公開されます。
* **明確な検討ルール（2段階ステージ制）**
  * **第1ステージ**: 投稿から7日間で**20人**の署名を集めるとクリア。
  * **第2ステージ**: 投稿から14日間（通算）で合計**30人**の署名を集めると、正式に生徒会や校則検討委員会での検討議題となります。
  * ※期間内に基準を満たさなかった意見は自動削除され、意見ボックスの視認性を保ちます。

---

## 🚀 利用の流れ

### 1. 初期設定
1. [proposal-jhs.ai.studio](https://proposal-jhs.ai.studio) にアクセス。
2. 「Googleログイン」から指定のアカウントでログイン。
3. 生徒会によるアカウント認証後、本格的に利用可能となります。
4. 「マイページ」よりクラスの設定を行ってください。

### 2. 意見を投稿する
1. 「意見を投稿」から疑問や提案内容を入力。
2. 「AIチェック」を実行し、問題がなければ「意見を提出」。
3. 教職員の承認後、意見ボックスに掲載されます。

### 3. 署名（賛同）する
1. 「意見ボックス」から賛同したい意見を選択。
2. 内容を確認し、「実名で署名（賛同）する」を押すことで署名完了。
